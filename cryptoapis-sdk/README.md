# cryptoapis-sdk

In-repo copy of the CryptoAPIs Node.js SDK. Generated from OpenAPI specification.

## API surface (dev reference)

Entry point: `dist/api.js` (or `dist/api.d.ts` for types).

Imports from this package:
- `CreateSubscriptionsForApi`, `ManageSubscriptionsApi`, `AddressLatestEVMApi`, `AddressHistoryEVMApi`, `TransactionsDataEVMApi`, `HDWalletDataUTXOApi`, `AddressLatestUTXOsApi`, etc.

See `dist/api.d.ts` for the full type exports.
